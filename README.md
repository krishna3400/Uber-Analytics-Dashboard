# Uber Ride Booking Analysis Dashboard

An interactive **Power BI** dashboard analyzing Uber ride booking data — covering completed and cancelled bookings, revenue, vehicle type performance, payment methods, and customer/rider behavior.

## 📊 Overview

This dashboard explores trip trends, demand patterns, and pricing insights from Uber's ride data. It is broken into multiple pages for focused analysis:

- **Home** – Landing page with project summary and navigation
- **Overview** – High-level KPIs: completed bookings, lost bookings, revenue, total distance, and average distance
- **Vehicle** – Booking and revenue breakdown by vehicle type (Auto, Bike, Go Mini, Go Sedan, Premier Sedan, Uber XL)
- **Revenue** – Monthly/quarterly revenue trends, revenue by vehicle type, booking value by payment type, and top revenue-generating customers
- **Rider** – Customer count trends, payment method distribution, ride cancellation reasons, and customer count by vehicle type
